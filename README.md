# Icy Tower - Neumorphism Edition ❄️

A modern HTML5 Canvas recreation of the classic **Icy Tower** game with a sleek, tactile **Neumorphism (Soft UI)** aesthetic.

## Features 🎮
- **Authentic Icy Tower Mechanics:**
  - Momentum-based acceleration and high-speed running.
  - Speed-boosted super jumps.
  - Wall bouncing physics to climb higher and chain jumps.
  - Multi-floor combo leaps ("Good!", "Sweet!", "Great!", "Super!", "AMAZING!").
  - Dynamic upward scrolling camera that speeds up as you climb.
- **Neumorphic Soft UI Design:**
  - Convex soft-shadowed cards and platforms with dual shadows.
  - Sunken tactile buttons and sunken screen bezel.
  - Custom HUD with score, floor, combo banners, and game-over modals.
- **Synthesized Audio:**
  - Real-time Web Audio API sound synthesis (zero external audio file dependencies).
- **Responsive & Mobile Ready:**
  - Touch controls (Left, Right, Jump) for smartphones and tablets.
  - Full keyboard support (`Arrow Keys` / `WASD` / `Space`).

## Controls 🕹️
- **Left / Right / A / D:** Run left & right.
- **Space / Up / W:** Jump.
- **Wall Bounce:** Hit the side walls while mid-air to rebound upwards!
- **Sound Toggle / Pause:** Header buttons.
